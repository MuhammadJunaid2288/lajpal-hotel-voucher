# LAJPAL TRAVEL LARKANA — Hotel / Umrah Voucher System

Sample (Sadabahar-style) layout pe multi-voucher generator.

## Features
- Multiple vouchers save
- Mutamers, Hotels (Makkah/Medina), Flights, Transport
- Agency name editable (default: LAJPAL TRAVEL LARKANA)
- Agent name, city, WhatsApp — sab editable
- PDF download (professional layout + QR)

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy online
GitHub pe upload karke Streamlit Cloud se deploy karein (pehle statement app jaisa).
